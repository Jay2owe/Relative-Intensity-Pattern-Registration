# Changelog

All notable changes to Log-Ratio Registration are documented here.

The project follows [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-08-21

### Added

- Robust gain-invariant log-ratio registration for ImageJ/Fiji time-lapses.
- Area-correlation estimator for image categories where validation supports it.
- Automatic, recommended, and fully manual parameter selection.
- Multi-channel and Z-stack transform application from a selected registration signal.
- Interactive parameter sweeps with preview overlays.
- Folder-batch processing with progress, cancellation, and CSV reporting.
- ImageJ macro recording, headless macro execution, and a public Java API.
