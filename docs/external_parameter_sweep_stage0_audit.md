# External parameter sweep: Stage 0 defaults audit

Audit date: 2026-08-20. The authority for every value below is the installed Fiji artifact recorded
and hashed in `library/benchmark/v2/runs/external_parameter_sweep_v1/plugin_versions.csv`. Evidence was
read from class bytecode with the installed JDK's `javap -p -c`, or from source embedded in the jar.
This makes the audit reproducible even if an upstream web page later changes.

## Result

The old harness did handicap three engine families. StackReg/MultiStackReg, Register Virtual Stack
SIFT, and Descriptor-based series registration were run with translation models even though their
installed dialogs default to rigid-body models. The SIFT descriptor size and three Descriptor-based
detection choices were also wrong. Those are harness corrections, not tuning. Fast4DReg's value `2`
was already correct, but the sweep plan's description of it as an upscale factor was wrong: it is a
peak-finder selector.

The old `external_comparison_v1` summaries are therefore retained only as the pre-correction record.
The corrected defaults run generated by this plan is the replacement baseline.

Across all 80 development inputs, square widths range from 96 to 252 pixels. The installed Image
Stabilizer gates enable level 1 on 52/80 recordings and level 2 on 21/80. Requested maximum level 2
is therefore meaningful only on that >=200 px subset.
No input reaches the 400 px threshold for level 3, so requested maxima 3 and 4 are expected to be
identical to maximum 2. Those predeclared candidates remain useful no-op controls and are reported as
such rather than described as deeper pyramids.

## Exact corrected defaults exposed by the harness

The `ExternalSettings` object prints these values into every result row:

```text
TurboReg model=rigid;
Image Stabilizer pyramid=1, update=0.9, iterations=200, tolerance=1.0E-7;
Fast4DReg peak method=2, normalized correlation=true;
Correct3D peaks=5, verify peaks=true;
SIFT model=rigid, sigma=1.6, steps=3, octave=64..1024, descriptor=8x8,
  rod=0.92, RANSAC=1000/25.0/0.05/2;
descriptor model=rigid, brightest=0, sigma=2.0/3.2, threshold=0.03,
  maxima=true, minima=false, localization=1, neighbors=3, redundancy=1,
  significance=3.0, RANSAC=5.0, regularize=false, fix first=true,
  global optimization=1, range=5;
reproducibility seed=69997
```

Non-estimation/output-control literals are also held in the settings object: Descriptor channels
0/-1, point ROIs false, silent true, fuse 2, and interpolation 0.

mpicbg itself initializes its shared RANSAC generator with seed 69997. The harness resets that
generator and Java's generator used by `Collections.shuffle` at each independent method/recording
boundary. This does not select a result; it makes an otherwise order- and clock-dependent default
as replayable as the installed implementation permits. A controlled one-active-processor probe still
varied because mpicbg's tile set ultimately depends on JVM object ordering. The Stage 1 report therefore
requires exact zero from the other eleven rows and reports Descriptor's observed replay spread rather
than hiding or rounding it away.

  `5fbff66501b191c8ab11b77364d1f5fa62d8d0b04649ce8856245a664f9a8821`.
- Sweep runs read `00_input_uncorrected.tif` and write only isolated CSV/log files under
  `library/benchmark/v2/runs/external_parameter_sweep_v1`; they do not rewrite recording folders.
- The evaluator installs a scoped uncaught-exception handler around each timed solve. A child worker
  exception therefore fails that row even if an installed plugin's parent call returns a partial model.
  An earlier partial baseline that exposed this Descriptor behavior was stopped and overwritten.
- Isolated sweep CSVs retain nine decimal places. A completed four-decimal diagnostic pass exposed
  that the earlier serializer could hide small replay differences; it was rejected and overwritten
  before any winner was selected.
- Rigid methods are scored by RMS displacement over the image field. For a pure translation this is
  algebraically identical to the historical Euclidean translation error; rotation is no longer
  silently ignored.
